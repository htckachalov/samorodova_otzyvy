# Как выложить витрину на GitHub Pages

## Что в папке
- `index.html` - сама витрина
- `data.js`, `app.js` - её начинка
- `web/part1 … web/part9` - 802 скрина, разложены по 100 штук

Самый тяжёлый файл - 713 КБ. Лимит GitHub на файл при загрузке через браузер - 25 МБ. Проходим с огромным запасом.

## Шаги

1. Регистрируешься на github.com (бесплатно).
2. Жмёшь **New repository**. Имя - например `otzyvy`. Ставишь **Public**. Create.
3. На странице репозитория: **Add file → Upload files**.
4. Перетаскиваешь `index.html`, `data.js`, `app.js`. Внизу кнопка **Commit changes**.
5. Снова **Add file → Upload files**. Перетаскиваешь папку `web/part1`. Commit.
   Важно: перетаскивать именно папку целиком, а не отдельные файлы - тогда структура сохранится.
6. Повторяешь для `part2`, `part3` … `part9`. Девять заходов, минут пятнадцать.
   Все они должны оказаться внутри папки `web`.
7. **Settings → Pages**. В разделе Source выбираешь ветку `main`, папку `/ (root)`. Save.
8. Через пару минут появится ссылка вида `https://твойлогин.github.io/otzyvy/`. Это и есть витрина.

## Если девять заходов лень
Скачай **GitHub Desktop** - там папка загружается целиком одним перетаскиванием, без ограничения в 100 файлов.

## Проверка
Открой ссылку с телефона. Если скрины не грузятся - значит папки `part…` лежат не внутри `web`. Поправить можно прямо на сайте, перетащив их в нужное место.
